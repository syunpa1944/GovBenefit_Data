# GovBenefit_Data

정부혜택달력(앱인토스 미니앱)이 실행 중에 읽어 오는 **공개 공공데이터 파일**입니다.
이 저장소에는 `data.json` 한 파일만 있으며, 앱 소스코드와 비밀값은 포함하지 않습니다.

- 파일: [`data.json`](./data.json) — 행사·혜택 1건마다 제목, 기간(`start`/`end`), 지역, 출처 링크, 연결 가능한 지역 혜택
- 갱신: 앱 저장소의 GitHub Actions 가 매일 00:00(KST) 공공 API를 수집해 자동으로 올립니다
- 사용: `https://raw.githubusercontent.com/syunpa1944/GovBenefit_Data/main/data.json`

## 출처

- 공연·전시·행사 정보: 한국문화정보원 [문화포털](https://www.culture.go.kr/) 「한눈에보는문화정보조회서비스」 (공공데이터포털 제공 Open API)
- 지자체 혜택·환급·시설 감면 정보: 각 지자체 공식 누리집 공고를 요약한 것으로, 항목마다 `source` 에 원문 링크를 적어 두었습니다
- 지역화폐 안내: 서울페이플러스, 인천e음, 동백전, 경기지역화폐 공식 안내 기준 (할인·캐시백 비율은 공고가 수시로 바뀌므로 수치를 적지 않습니다)

공공데이터는 제공기관의 이용허락 조건(공공누리)을 따르며, 재사용 시 출처를 표시해 주세요.
금액·기간·자격 조건은 수집 시점 기준이므로 신청 전 반드시 원문 출처에서 확인하시기 바랍니다.
